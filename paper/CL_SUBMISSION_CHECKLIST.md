# Computational Linguistics Journal Submission Checklist

## Pre-Submission Requirements

Based on official CL journal guidelines (MIT Press) - Updated January 2025

### 1. Manuscript Format ✓ TO DO
- [ ] Use **clv2025.cls** LaTeX class file (NOT acl2024.sty)
- [ ] Download style files from: submissions.cljournal.org/index.php/cljournal/StyleGuide
- [ ] Review COLI-manual.pdf for formatting instructions
- [ ] Use COLI-template as reference for structure

### 2. Author Information ✓ TO DO
- [ ] **Include author names and affiliations** (single-blind review)
- [ ] Remove "Anonymous ACL Submission"
- [ ] Add contact author's email address
- [ ] Provide author information in both:
  - [ ] PDF manuscript (first page)
  - [ ] Separate text file (title, authors, abstract, contact email)

### 3. Length Requirements
- [ ] Verify paper length:
  - Long papers: **25-40 journal pages**
  - Short papers: 15-25 journal pages
  - Squibs: ≤8 pages
- [ ] Our target: **Long paper** (comprehensive benchmark study)

### 4. Abstract ✓ TO DO
- [ ] Word count: **150-250 words** (informative abstract)
- [ ] Current abstract word count: ~250 words ✓ (verify after formatting)
- [ ] Clearly states: problem, methods, results, contributions

### 5. Typography & Formatting
- [ ] All text in Times Roman (or Times New Roman/Computer Modern Roman)
- [ ] Single-spaced formatting
- [ ] Title: 15-point bold, centered, 2.5 cm from top
- [ ] Follow CL journal style guide exactly

### 6. References & Citations ✓
- [ ] Use CL journal citation style (from compling.zip)
- [ ] Verify all references are complete and properly formatted
- [ ] Check reference list against cljournal style requirements
- [ ] Current: 50+ NLP/ML citations in references_cl.bib

### 7. Content Requirements
- [ ] Introduction clearly motivates the problem
- [ ] Related work comprehensively covers relevant literature
- [ ] Methodology section is reproducible
- [ ] Results include statistical significance where appropriate
- [ ] Discussion addresses limitations
- [ ] Conclusion summarizes contributions

### 8. Figures, Tables, and Algorithms
- [ ] All figures have captions and are referenced in text
- [ ] Tables are properly formatted with booktabs style
- [ ] Algorithms (if any) follow CL formatting
- [ ] Font sizes in figures/tables are readable (updated Jan 2025 guidelines)

### 9. Supplementary Materials
- [ ] Code repository: GitHub (An-Adaptive-Methodology)
- [ ] Dataset: Available (2,968 texts, balanced)
- [ ] Trained models: Available
- [ ] Consider data/code availability statement in paper

### 10. Ethics & Reproducibility
- [ ] Limitations section (if applicable)
- [ ] Ethical considerations (if applicable)
- [ ] Reproducibility information:
  - [ ] Code availability
  - [ ] Dataset availability
  - [ ] Model hyperparameters documented

### 11. Final PDF Generation
- [ ] Generate PDF from LaTeX source
- [ ] Verify PDF displays correctly
- [ ] Check all fonts are embedded
- [ ] File size is reasonable
- [ ] No compilation warnings/errors

### 12. Pre-Submission Files
Prepare these files for submission:

1. **Main manuscript PDF**
   - Format: PDF
   - Content: Complete paper with author info
   - Naming: `computational_linguistics_submission.pdf`

2. **Separate text file**
   - Format: .txt
   - Content: Title, authors, abstract, contact email
   - Naming: `manuscript_metadata.txt`

3. **LaTeX source files** (if requested)
   - .tex file
   - .bib file
   - Any custom style files
   - Figures/tables

### 13. Online Submission Portal
- [ ] Create account at: submissions.cljournal.org
- [ ] Upload PDF manuscript
- [ ] Upload metadata text file
- [ ] Select manuscript type: **Research Article (Long Paper)**
- [ ] Provide keywords
- [ ] Suggest potential reviewers (if requested)
- [ ] Confirm no conflicts of interest

## Key Differences from ACL Conference Submissions

| Aspect | ACL Conferences | CL Journal |
|--------|----------------|------------|
| **Format** | acl2024.sty | clv2025.cls |
| **Review** | Double-blind (anonymous) | Single-blind (named) |
| **Length** | 8 pages + refs (short/long) | 25-40 pages (long paper) |
| **Abstract** | No strict limit | 150-250 words |
| **Timeline** | Fixed deadline | Rolling submissions |
| **Venue** | Conference proceedings | Peer-reviewed journal |

- Review process takes 3-6 months typically
- Single-blind: reviewers know authors, authors don't know reviewers
- High-impact journal (flagship publication of ACL)
- Focus on substantial, original contributions to computational linguistics
